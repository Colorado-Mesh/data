### MeshCore and Meshtastic Snapshots

Snapshots of known Meshtastic and MeshCore nodes and coverage are taken every hour or so (via GitHub Actions) from various online sources and cached in this repository. These snapshots are used as semi-comprehensive data sources for Meshtastic and MeshCore nodes.

This data is actively used by the [coloradomesh_python](https://github.com/Colorado-Mesh/coloradomesh_python) library as "live" data to reduce the load on external data sources.
